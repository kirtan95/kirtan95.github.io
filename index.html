PROJECT 01 · AI AGENT

Agentic Workflow Assistant

A Slack assistant built to complete bounded, multi-step work instead of returning a single model response.

Problem

General assistants often lose context across turns and fail unpredictably when a tool call breaks.

Approach

A Claude tool-use loop is capped at eight iterations, dispatches web search, a parser-based calculator, and persistent notes, and feeds tool errors back into the loop. Postgres stores conversation memory and summaries.

Outcome

The same runAgent() path powers Slack Socket Mode and a terminal REPL. Offline node:test coverage exercises the tools and agent behavior without Slack credentials.

Tech stack

  • Claude tool use
  • Slack Bolt
  • PostgreSQL

PROJECT 02 · RETRIEVAL

RAG Knowledge Assistant

An operable document Q&A service that keeps ingestion, retrieval, grounding, and evaluation visible.

Problem

Notebook RAG demos can hide the retrieval path and make it difficult to tell whether an answer is grounded in the source material.

Approach

FastAPI ingests text, Markdown, and PDF files, chunks them by token with overlap, embeds with MiniLM, and ranks top-k chunks in Postgres using pgvector cosine distance. Claude generation stays optional.

Outcome

Retrieval works without an LLM key, while generated answers cite their context when enabled. A ten-question harness reports hit-rate@k and MRR; offline tests cover chunking, extraction, and ranking.

Tech stack

  • PostgreSQL

PROJECT 03 · FULL STACK

Finance Tracker

A full-stack personal finance platform for turning account and bank-statement data into a dependable ledger and clear monthly summaries.

Problem

Overlapping CSV statements can duplicate transactions, while stored account balances can drift away from the ledger that should define them.

Approach

FastAPI and React model users, accounts, transactions, categories, and budgets. Imported rows use a SHA-256 fingerprint plus a unique constraint, and balances are derived from transactions instead of stored separately.

Outcome

The app provides authenticated CRUD, filters, budget progress, category spending, income-versus-expense trends, and net-worth summaries. Pytest covers auth, CRUD, idempotent imports, and summary math offline.

  • SQLAlchemy
  • PostgreSQL
  • Chart.js
  • Docker Compose

PROJECT 04 · REAL TIME

The Mole’s Tale

A real-time word party game where 3 to 8 players build a shared story while trying to hide secret words from one another.

Problem

A multiplayer party game needs near-zero onboarding and synchronized turns, rooms, voting, and scoring across phones and laptops.

Approach

A single Node.js process uses WebSockets and four-letter room codes to run the lobby, timed story turns, reveal, voting, and scoring phases without logins or installs.

Outcome

Players can complete configurable multi-round games in the browser. An automated test simulates four players through two full rounds and asserts the scoring rules.

Tech stack
  • Node.js
  • WebSockets
  • Room codes
  • Responsive UI
  • Automated game test
